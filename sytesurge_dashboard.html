Setup Guide
One-time setup to connect Gmail with real OAuth — no passwords ever
Why OAuth and not a password? With OAuth, you log in directly through Google's own screen — Sytesurge never sees your password. Google gives the app a temporary access token instead. It's the same way "Sign in with Google" works on any website. Your credentials stay entirely with Google.
1
Host on GitHub Pages
The dashboard must be at a fixed URL so Google knows where to redirect after login.

1. Create a free account at github.com
2. Click New repository → name it sytesurge
3. Upload this HTML file as index.html
4. Go to repo Settings → Pages → set Source to main branch
5. Your URL will be:
https://YOURNAME.github.io/sytesurge

✅ Open that URL in your browser — use it from now on instead of this Claude window.
2
Create Google OAuth App
1. Go to console.cloud.google.com
2. Create a new project (e.g. "Sytesurge")
3. Go to APIs & Services → Enable APIs
   → Enable Gmail API
4. Go to OAuth consent screen
   → External → fill in App Name
   → Add your Gmail as test user
5. Go to Credentials → Create Credentials → OAuth 2.0 Client ID
   → Type: Web Application
6. Under Authorized redirect URIs add:
https://YOURNAME.github.io/sytesurge
7. Copy your Client ID
3
Connect Gmail
1. Open the dashboard from your GitHub Pages URL
2. Paste your Client ID below and save
3. Click Connect Gmail in the header
4. Google's login screen appears → sign in as info@sytesurge.com
5. Approve the Gmail send permission
6. You're redirected back → header shows ✓ Connected

✅ Done! The token is saved in your browser. You won't need to reconnect unless you clear browser data.
